# Wedding Website Design Implementation Guide

## 🎨 Overview

This guide outlines the assets, typography, layout, and tools needed to recreate a modern, elegant wedding website similar to the provided mockup.

---

# 🧩 Required Assets

## 1. Photography

High-quality images are critical.

### Required:

* Hero image (wide, cinematic)
* 3–6 gallery images
* Mobile-friendly crops

### Style Guidelines:

* Cool tones (bluish tint)
* Soft contrast
* Slight glow or haze
* Consistent color grading

---

## 2. Decorative Graphics

* Floral elements (PNG or SVG with transparency)
* Watercolor textures
* Subtle paper grain overlays

---

## 3. Icons

Use minimal line icons:

* Calendar
* Location
* Dress code
* Gift/registry

### Style:

* Thin stroke (1–1.5px)
* Monoline
* Rounded edges

---

# 🔤 Typography

## Primary Font (Headings)

**Playfair Display**

* Use for names and titles
* Elegant serif style

## Secondary Font (Body)

**Inter**

* Clean and modern
* Highly readable

## Optional Accent Font (Script)

* Great Vibes
* Allura
* Parisienne

Use only for small accents like “and”

---

# 📏 Font Sizes

## Landing Page

* Names: 64–96px
* Date: 14–18px
* Small text: 12–14px

## Main Page

* Hero title: 48–72px
* Section titles: 20–28px
* Body text: 14–16px
* Labels: 12–14px

### Letter Spacing

* Headings: 0.05em – 0.1em
* Small text: 0.1em – 0.2em

* Primary Blue: #6B7C93

# 📐 Layout Structure

## Landing Page

* Full-screen centered card
* Floral decorations
* Click-to-enter interaction

## Main Page Sections

### 1. Hero

* Large image
* Centered overlay text

### 2. Gallery

* 3 horizontal images

### 3. Wedding Details

* 4-column grid:

  * Date
  * Location
  * Dress code
  * Registry

### 4. RSVP Section

* Highlighted background block
* Centered button
