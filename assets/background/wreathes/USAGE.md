# Asset Category Guidelines: Wreathes

## 1. Folder Purpose & Scope
This directory contains static framing and accent assets designed to frame content or act as decorative sticker highlights.

- **Behavior & Flexibility:** Assets can be used as framed borders, focal accents, or static stickers behind hero elements, titles, or badges.
- **Animation Restriction:** These assets are strictly **static** and must **not** be used in dynamic motion or loop animations.
- **Visual Goal:** Provide deliberate focal points and decorative framing around central content.

## 2. Naming Conventions & Metadata
- **File Prefix System:** All filenames follow a categorized prefix format (e.g., `floral_*`, `non-floral_*`). Use these prefixes to infer visual characteristics if direct vision/image analysis capabilities are unavailable.
- **Selection & Distribution:** Utilize prefixes to maintain a balanced, diverse selection across categories. Select assets dynamically based on user prompts and creative intent.

## 3. Selection Rules for AI
- Position directly behind or around central text, badges, or photo containers to act as a frame.
- Maintain original aspect ratios to avoid warping ornate wreath details.
- Never pass these assets into animation loops or physics engines.
